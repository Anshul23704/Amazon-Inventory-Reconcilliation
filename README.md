Project Overview
This repository contains implementations of SVM and CNN models for dataset classification, along with accompanying documentation and project materials.

1.Dataset Access
The dataset used in this project can be accessed from the following Google Drive link:
Dataset Link : https://drive.google.com/file/d/17iVPnXoJXo_O5zLx_MbvXUmipyhn03A4/view?usp=drive_link

The dataset is organized into two main folders:
SVM/
CNN/


2.CNN Model
The CNN folder contains:
CNN_model/ – Stores the trained CNN model generated using training.py.
CNN_training.py – Trains a Convolutional Neural Network using the SGD (Stochastic Gradient Descent) Adam optimizer for classification.
CNN_evaluate.py – Evaluates the trained CNN model and reports performance metrics.

3.SVM Model
The SVM folder contains:
SVM_hog.py – Implements SVM classification using Histogram of Oriented Gradients (HOG) features.
It classifies the dataset and generates evaluation metrics based on the predictions.

4.Additional Files
The repository also includes:
🧾 Research Paper – The paper on which this project is based.
📄 Project Report – Detailed report documenting the methodology and results.
🎯 Presentation – A concise overview of the project, summarizing key findings and outcomes.

This project demonstrates two approaches to image/data classification:
A traditional Machine Learning approach (SVM + HOG)
A Deep Learning approach (CNN)
